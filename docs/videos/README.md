## Transcript / 文字步驟

1. Open UI Inspect and review the highlighted language choice. / 開啟工具，確認發亮的語言選項。
2. Expand the card container; hover a layer, then click the first card. / 展開卡片容器，Hover 圖層再點選第一張卡。
3. Step 2: choose the same `.card` class and exclude the second card. / 選同 class，將第二張設為例外。
4. Step 3: request orange cards while keeping the second unchanged, then use Copy change request. / 填入「改橘色、第二張不改」，複製修改需求。
5. Prepare a screenshot. The outlined target and readable change brief remain together; the preview changes to 100%. / 準備截圖，選取框與修改單同時保留，預覽改成 100%。

Pause or replay any step. For complete text and all keyboard shortcuts see [English](../HOW-TO.en.md), [繁中](../HOW-TO.zh-TW.md), [Français](../HOW-TO.fr.md), [日本語](../HOW-TO.ja.md).
