換成自己的本機預覽 / Use your local preview

先確認測試資料及分析停送。localhost 也可能連到真實後端；本工具不會替你阻擋網站分析或交易。

怎麼檢查？尺寸準確嗎？ / How to check and limitations

先看 320、390、768、1280，再輸入你的斷點前後寬度。每個寬度檢查：橫向溢出、文字截斷、選單、表單及鍵盤焦點。預覽不會自動宣告通過。

尺寸單位是 CSS px。機型為近似排版參考，不會改 User-Agent、DPR、觸控、瀏覽器引擎或安全區。手機瀏覽器工具列、縮放和系統顯示設定會改變實際可視範圍。最新機型資料核對日：2026-09-15。

Preview only changes the iframe layout size, not the browser engine or device. Check real Safari/Android separately. A clipped frame on your desktop can be scrolled horizontally; it is not automatically a page defect.
