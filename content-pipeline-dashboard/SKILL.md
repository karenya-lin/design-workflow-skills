# Content status / 內容產線進度

Read [optional profile](../optional-skill-profile/SKILL.md) if available. Ask which
sources and stages apply: planning inventory, drafts, media, review, upload and public
publication. Connections are optional; do not inherit a company's account/folders.

Use stable content ID plus locale as the join key. Confirm ambiguous matches rather
than joining by a similar filename. Define evidence for each stage before marking
it complete: a file present, review accepted, uploaded privately and publicly live
are different facts. Missing source access is unknown, not missing deliverable.

Build a compact matrix with completed/in progress/missing/not applicable/unknown,
owner, dependency, next step and source timestamp. Distinguish human decisions from
agent work. Keep references to private material in private outputs only; public
dashboards use sanitized counts and synthetic examples.

Inspect any existing generator before reuse. If none exists, agree on a new artifact
and input schema; do not claim absent helper scripts ran. Validate duplicate IDs,
locale gaps and source disagreements. Updating a dashboard does not authorize uploads,
publishing, deleting drafts or changing another owner's files.

繁中：以內容 ID × 語系對帳，區分本機、已審、已上傳與已公開。
來源讀不到要標未知；面板可以彙整，但不能因此自行發布內容。
